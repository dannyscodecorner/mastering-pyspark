# Mastering PySpark

Welcome to **Mastering PySpark**, a Danny’s Code Corner course on how Spark works and how to use it. Follow the presentation, then put the ideas into practice in the hands-on lab.

## Follow the course

**[Open the hosted slides](https://dannyscodecorner.github.io/mastering-pyspark/)**

The presentation runs in your browser. Use the arrow keys to move between slides, **O** to browse the sections and **F** for full screen.

## Get hands-on

**[Start with the lab setup guide](labs/README.md)**

Build a category sales report from Parquet data: inspect and clean the inputs, join and aggregate them, then run the same pipeline as new files arrive. The lab guide walks you through installation, VS Code setup and your first notebook, **Exercise 0 — Create a SparkSession**.

Each exercise has its own notebook. Choose how much detail to explore:

- **About 60 minutes:** complete the core tasks.
- **About 90 minutes:** add the optional zoom-ins in those same notebooks.
- **At your own pace:** follow the linked deeper investigations.

You can choose extra detail topic by topic. Complete setup before the session; these times are for the exercises.

Keep the [API reference](labs/docs/API-REFERENCE.md) nearby, and use [troubleshooting](labs/docs/TROUBLESHOOTING.md) if you get stuck with setup.

## What you’ll learn

- How Python and Spark work together, and why Spark distributes work.
- DataFrames, transformations, actions and lazy evaluation.
- Query plans, joins, grouping and aggregation — including shuffles and skew.
- Structured Streaming: execution modes, output modes and checkpointing.
- Building a PySpark pipeline and taking Spark into AWS Glue.
